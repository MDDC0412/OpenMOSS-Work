# 创作台 · 个人 AIGC 平台

本机运行的个人创作工具：自己填供应商的 **Base URL、API Key、模型列表接口**，平台先用模型列表接口做连通性体检，再把各家 API 的请求参数变成可视化表单。支持对话、生图（文生图 / 改图 / 多张）、作品库存档，提示词包跨模态共用。

> 个人自用，非商用平台。没有导演台、分镜、时间线、工作流市场那一套。视频本期只留导航入口，第二期开放。

## 快速开始

需要 **Node.js 24+**（用到内置的 `node:sqlite`）。

- **最简单**：双击 `start.cmd`。首次会自动 `npm install`，随后启动开发服务器并自动打开浏览器。
- **手动**：

  ```bash
  npm install
  npm run dev
  ```

打开 <http://localhost:3000>，默认落在「供应商」页。在窗口里按 `Ctrl+C` 停止服务。

## 数据放在哪

所有用户数据都在**项目目录之外**，不会被 git 提交、也不会被网盘同步走：

```
%APPDATA%\AIGC-Creation-Platform\
├─ platform.db      SQLite 库（供应商 / 模型 / 会话 / 作品 / 提示词包 / 偏好）
├─ works\           生成的图片（作品库只列这里）
└─ uploads\         改图上传的原图（属于输入素材）
```

- API Key 以**明文**存进本机数据库，但放在项目外；界面上只显示掩码 `********`，日志里不打印。
- 左侧导轨底部常驻显示数据目录，随时能核对；**点它就能改存放位置**：填一个空文件夹的完整路径，数据库、作品、上传原图整份搬过去，立即生效不用重启。目标必须是空文件夹（或不存在）、不能和旧目录互相嵌套；中途失败自动搬回原目录。锚点目录里只留一个 `data-dir.json` 指针文件记住新位置，「恢复默认目录」即搬回并删掉指针。
- 想清空重来：关掉服务后删掉上面整个文件夹即可，下次启动自动重建。

## 功能一览

| 页面 | 能做什么 |
| :-- | :-- |
| **供应商** | 一行一个供应商：Base URL + Key + 模型列表接口；一键体检（区分网络 / 鉴权 / 地址 / 超时 / 限流 / 上游 / 响应异常，给中文结论）；成功后列出可用模型并分类 对话 / 图片 / 视频，用途可手工锁定 |
| **对话** | 流式输出；会话与消息持久化，可回看续聊；`@` 提及提示词包 |
| **生图** | 文生图、改图（原图可上传或从作品库选）、一次多张（`n`）；生成中绘制区有显影动效与等待计时；参数可视化表单：画幅（形状／宽高比）、分辨率档位（480p / 720p / 1K / 1.5K / 2K / 2.5K / 4K）、输出预览框（形状＋实际像素）、`quality`、`complexity`、`output_format`、`output_compression`、背景、风格 |
| **作品库** | 本机存档；回看 / 重新下载 / 查看参数；一键拿作品当原图进改图；**右键作品卡 → 在资源管理器打开**（直接选中图片文件）；按 文生图 / 改图 过滤；删除会连图片文件一起清掉 |
| **提示词包** | 外链或本地文本文件（上限 5MB），抓取／导入并缓存；跨对话 / 图片 / 视频共用 |
| **视频** | 仅导航入口，标注「第二期」，本期不可用 |

## 供应商接入

内置两家已核实的一键预填（地址与接口路径都确定，只需粘自己的密钥）：

- **String AI** — `https://www.string.ink/v1`，模型列表 `/v1/models`（带 `type` 与 `display_name`）。
- **xiaopangAPI** — `http://103.236.98.145:28475/v1`，New API 网关，模型列表 `/v1/models`（只有 `id` / `owned_by`，用途靠名字规则猜）。

也可以填任意兼容 OpenAI 接口的供应商。体检只调模型列表接口，不会消耗生成额度。

模型用途有三个来源，优先级 **手工 > 供应商声明 > 名字猜测**；体检刷新只覆盖后两者，手工改过的行永不被冲掉。

## 原始请求面板

每个创作页都是**表单为主 + 只读原始请求面板**：

- 平时表单可改，右侧实时显示将要发出的请求 JSON（只读）。
- 点「**修改原始请求**」后可编辑 JSON，此时表单选项**变灰**，以你手写的请求为准。
- 点「**放弃修改，回到表单**」丢弃手写内容，恢复表单驱动。

## 提示词包与润色

- **提示词包**就是一段纯文本，不做解析拆条。两种来源：**外链 URL**（填地址，抓回来缓存）或**本地文件**（选 .txt / .md，浏览器直接读文本存进来，不上传服务器）。文本上限 **5MB**。在对话里 `@某个包`，就是把该包文本追加进这条消息的 prompt；图片、视频模型只要能入参当 prompt，同样可用。外链包可「重新抓取」，本地包可「重新导入」换文件。
- **润色**：提示词框旁的按钮，调一个对话模型按目标模态（对话 / 生图）改写草稿，只回填改好的文本。

## 便携版打包

`next.config.ts` 开了 `output: 'standalone'`，构建会把服务端运行所需的最小文件集 trace 到 `.next/standalone`。打包步骤（产物放项目外）：

```bash
npm run build
# 组装便携目录（示例路径，可换）
PKG="../AIGC-Creation-Platform-portable"
mkdir -p "$PKG"
cp -r .next/standalone/. "$PKG/"
mkdir -p "$PKG/.next/static"
cp -r .next/static/. "$PKG/.next/static/"
# 再放入 start.cmd 与 使用说明.txt（仓库外成品里已有），压缩：
tar -a -cf AIGC-Creation-Platform-portable.zip AIGC-Creation-Platform-portable
```

成品约 26MB（zip 约 25MB）。目标机只需 **Node.js 24+**，不用装任何依赖：双击 `start.cmd` 即在 `127.0.0.1:3000` 起服务并自动开浏览器，关窗口即停。数据仍在 `%APPDATA%`（或自定义目录），与开发版共用；便携文件夹可随意搬动。

## 边界说明

- 视频：第二期开放，本期只有占位页。
- 生图不做「变体 / variations」（New API 该路由未实现）。
- 画幅与分辨率档位都不是 API 参数：OpenAI 生图只认像素 `size`。三个概念各管一件事——**画幅**＝宽高比（形状），**分辨率**＝清晰度档位（决定长边像素，480p→854 … 4K→3840），**质量**（`quality`）＝模型渲染精细度、与分辨率无关。发请求时按「画幅 × 分辨率」换算成一个 `size`（宽高取 16 的倍数），预览框显示最终形状与实际像素。要精确到某个像素值，去「修改原始请求」改 `size`。
- `output_compression` 只对 `webp` / `jpeg` 生效，选其它格式时界面会清空并置灰该项。
- 改图引用作品库时直接读作品文件，不往上传目录拷贝；作品被删后引用会明确报错。作品卡与生成结果的「拿去改图」经 `/image?edit=<id>` 带上原图。
- 真实密钥与生成数据一律放项目外，不进仓库。
